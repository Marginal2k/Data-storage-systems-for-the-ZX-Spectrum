Пакет VU
Пакет состоит из программ:
VU Calc, VU File и VU 3D, записанных на диски.

Версия D80
Введите RUN для запуска главного меню,
LOAD *"A" для программ на английском языке и *"B"
для версий от INVEStrуnica, а также для
демо-версий.

Примечание:
Поскольку система Didaktik использует
точку для добавления однобуквенного расширения, характерного для системы, я решил использовать запятую и знак «@» для обозначения своих собственных расширений в именах, таких как, например, «vc,scr» для файла SCREEN$ и «demo@vf» для имен файлов VU-file. В случае с VU-calc и VU-3d я выбрал «@vc» и «@v3» соответственно, с единственной целью — обеспечить большую ясность.
VU-file. В случае с VU-calc и VU-3d я выбрал, соответственно, «@vc» и «@v3», с единственной целью — сделать содержимое каталога на диске более понятным.
